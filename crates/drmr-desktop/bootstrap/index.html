drmr

Use the File menu to choose your input folder and an output location, then select Open console.

The output location contains a private drmr-output folder. Your input files remain in their original folder.

For encrypted media or authenticated downloads, select an optional private configuration folder before opening the console. Keep this folder separate from the input and output folders. Choose existing private JSON files in the console; their contents are not uploaded through the browser.

The console uses the same local server as drmr serve for analysis, saved plans, conversion, and independent verification. Media tools must be installed separately.
